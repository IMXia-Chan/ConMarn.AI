法律信息

隐私政策

最后更新：2026-11-08　·　适用于 ConMarn 3.1 及后续版本

ConMarn 是一个运行在用户自有设备上的本地优先程序。本政策逐项说明程序在运行过程中会接触到的数据、这些数据的存放位置，以及在什么条件下才会离开设备。

概要

本项目不设账号体系，不收集使用统计，不集成分析、崩溃上报或广告组件。程序的默认状态是不向任何外部服务发送数据。

我们不收集的信息

  • 不要求注册或登录，不存在账号与服务器端用户档案。
  • 不采集设备标识符、通讯录、位置、通话记录与短信内容。
  • 不内置埋点、崩溃上报或广告组件。

在本机读取的数据

下列数据仅在本机内存或应用私有目录中处理，不写入共享存储，也不随任何请求发出。

  • 麦克风音频：仅在唤醒词被触发或用户主动发起语音输入时采集，用于唤醒词检测、语音活动检测与本地语音识别；识别完成后释放。
  • 摄像头画面：仅在用户主动使用相关功能时调用，处理在本机完成。
  • 屏幕内容：仅在用户主动使用投屏或视觉定位功能时获取。
  • 剪贴板、通知与已安装应用列表：仅在用户明确下达相关指令时读取，用于执行该指令。
  • 无障碍服务：用于在本机读取界面结构与执行点击。

存储位置

模型文件、素材、记忆库、任务档案与运行日志均保存在应用私有目录内。卸载程序时，上述数据随应用一并删除。本项目不提供云端备份。

数据外发

程序全部对外网络访问由一处总开关统一控制，该开关默认关闭。开启后：

  • 仅发送文本。截图、音频与视频不随请求发出。
  • 请求发往用户自行配置的 API 端点与服务密钥，该端点的数据处理行为由对应服务商负责。
  • 内置天气查询使用 open-meteo；新闻与语录来源可在设置中关闭。

关闭总开关后，上述请求全部停止。

权限与用途

  • 麦克风：唤醒词检测与语音输入。
  • 摄像头：用户主动发起的媒体采集。
  • 悬浮窗：常驻入口与语音状态显示。
  • 无障碍：界面读取与点击执行。
  • 通知监听：当前版本未启用。
  • 网络：局域网内设备发现，以及用户在开启总开关后主动发起的请求。

局域网内的电脑端

与已配对电脑之间的通信仅在同一网段内进行，内容经配对时协商的密钥加密，并逐条校验。

未成年人

本程序不面向未满十四周岁的未成年人单独使用。

变更与联系方式

本政策的修订随版本发布，并更新页面顶部的日期。问题与请求请提交至 GitHub Issues。
