Privacy Policy

Last updated 2026-11-08　·　Applies to ConMarn 3.1 and later

ConMarn is a local-first program that runs on the user's own device. This policy states, item by item, what data the program touches while running, where that data is stored, and under what conditions it leaves the device.

Summary

The project has no account system, collects no usage statistics, and bundles no analytics, crash reporting or advertising components. In its default state the program sends no data to any external service.

What we do not collect

  • No registration or sign-in is required; no account or server-side profile exists.
  • No device identifiers, contacts, location, call logs or message contents are collected.
  • No telemetry, crash reporting or advertising components are embedded.

Data read on the device

The following data is processed only in device memory or the app's private directory. It is not written to shared storage and is not sent with any request.

  • Microphone audio: captured only when the wake word is triggered or the user starts a voice turn; used for wake-word detection, voice activity detection and local speech recognition, then released.
  • Camera frames: accessed only when the user starts a related feature; processed on the device.
  • Screen content: accessed only when the user starts screen casting or visual grounding.
  • Clipboard, notifications and installed app list: read only when the user gives a related instruction, and only to carry it out.
  • Accessibility service: used to read the interface structure and perform taps on the device.

Where data is stored

Model files, assets, the memory store, task records and runtime logs all live in the app's private directory. Uninstalling the app deletes them together with the app. The project provides no cloud backup.

Data leaving the device

Every outbound network request is governed by a single master switch, which is off by default. When it is on:

  • Only text is sent. Screenshots, audio and video are never included in a request.
  • Requests go to an API endpoint and key configured by the user; how that endpoint handles data is the responsibility of its provider.
  • The built-in weather lookup uses open-meteo; news and quotation sources can be turned off in settings.

Turning the master switch off stops all of the above.

Permissions and their purpose

  • Microphone: wake-word detection and voice input.
  • Camera: media capture the user starts explicitly.
  • Overlay: the persistent entry point and voice-state indicator.
  • Accessibility: reading the interface and performing taps.
  • Notification access: not enabled in the current version.
  • Network: discovering devices on the local network, and requests the user starts after enabling the master switch.

The paired computer on the local network

Traffic to a paired computer stays within the same subnet, is encrypted with a key agreed at pairing time, and is verified item by item.

Minors

The program is not intended for use by minors under 14 without supervision.

Changes and contact

Revisions to this policy are published with each release and the date above is updated. Questions and requests belong in GitHub Issues.
