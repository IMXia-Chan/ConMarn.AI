# ConMarn

**ConMarn** 是一个住在你手机里的 AI 伙伴。

她有自己的大脑 —— **在你自己的手机上本地运行**，断网也能思考、也能开口。她听得见你说话，
看得见屏幕上的东西，有自己的嗓音和模样。她能隔着 Wi-Fi 连上你的电脑，替你点、替你打字、替你开应用。

她和你的相处会留在她身上：说过的话、在一起多少天、今天过得怎么样。

## 她需要什么才跑得起来

安装包里**不含**模型文件。她的大脑、眼睛、耳朵、嗓子加起来约 5 GB，需要单独下载后放进手机上。

| 用途 | 模型 | 大约大小 |
|---|---|---|
| 思考（大脑） | Qwen3-4B-Instruct-2507 · Q4_K_M（GGUF） | 2.3 GB |
| 看屏幕（眼睛） | Qwen3-VL-4B-Instruct · Q4_K_M ＋ 视觉编码器 | 2.9 GB |
| 听（耳朵） | sherpa-onnx SenseVoice（中／英／日／韩／粤） | 228 MB |
| 唤醒词 | sherpa-onnx KWS（中文，约 3.3M 参数） | 5 MB |
| 声纹 | 3D-Speaker ERes2Net（中文，16 kHz） | 26 MB |
| 人声检测 | Silero VAD | 644 KB |
| 说话（嗓子） | VITS 中文（模型 ＋ 词典 ＋ 声码器） | 116 MB |

这些大多是公开模型，在 HuggingFace / ModelScope 上能找到同名的仓库。
**具体下载地址和放置目录以应用里的指引为准** —— 不同版本要的文件不完全一样。
她的模样是内置的，想换的话放一个 VRM 格式的人物模型进去就行。

## 她会做什么

**陪着你**

- 大脑在手机上本地跑，断网也在
- 叫一声唤醒词她就应，之后可以连着聊，不用反复喊
- 有自己的嗓音和形象
- 她的性格、情绪、和你的相处时间，都可以在应用里自己调

**替你动手**

- 手机经 Wi-Fi 连上电脑：触控板、屏幕镜像、摄像头／麦克风、文件中转站
- 看得见电脑屏幕上的东西，能点、能打字、能开应用
- 会碰到钱和账号的动作，先问你

---

## 隐私

- 她的大脑跑在**你自己的手机上**，不是别人的服务器
- **截图永远不出手机**
- 声音不出手机 —— 除非你自己把它接到自己的服务器上，而且是你亲手打开的
- 你填的 API Key 只存在本机加密区
