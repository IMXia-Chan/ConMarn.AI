        说明
        

          
        演示模式。开启后界面显示内置的示例数据,不读取电脑端服务的状态,
            因此画面中不会出现真实的局域网地址、目录路径、文件名与配对码;开关、传输与配对等操作
            只在界面内改变状态,不会实际执行。关闭后立即恢复真实数据。该开关只影响本程序的显示,
            不影响后台服务。
        

          
        与电脑端服务的关系。本程序只是界面,不包含配对、加密与文件协议;
            这些功能由后台运行的电脑端服务提供。关闭本程序不影响手机连接,服务继续运行。
        

          
        开机自启。开关控制的是电脑端服务的自启项,不是本程序。
            修改只影响下次登录;当前正在运行的服务不受影响。
        

          
        配对。电脑端服务的配对信息由登录 PIN 保护,输入登录 PIN 后才会显示配对二维码。
            二维码与配对码都是一次性的。解除配对会清除本机保存的配对密钥,手机需要重新配对。
        

          
        媒体。摄像头与麦克风的开关与手机上媒体面板的开关发送同一条指令;
            电脑端未连接手机时,指令不会送达。
        

          
        文件。本地中转目录与手机中转目录互传文件,取回与发送均由电脑端服务执行。
            手机侧列表需要手机处于连接状态并打开文件面板。
        

          
        安全。本程序的界面服务只监听本机回环地址,局域网内的其他设备无法访问。
